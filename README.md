# Goal Tracking Mobile Application

The Goal Tracker Mobile Application is designed to help users set, manage, and achieve their personal goals. The application allows users to create goals, set deadlines, track their progress, and mark goals as completed. Users can also update or delete goals as needed. The purpose of this application is to help users stay organized, motivated, and focused on accomplishing their daily, weekly, or long-term goals.

## Week One

During the first week, the group focused on setting up the foundation for the Goal Tracker Mobile Application. We selected Goal as the main domain entity, which will represent the goals users create and manage within the application. The entity will include properties such as GoalId, Title, Description, Deadline, Progress, and IsCompleted.

We also worked on setting up the .NET MAUI project to begin developing the mobile application using C# and XAML. For data storage, we haven't decided which one we will us yet but by week two we should have that figured out. We will also decide on having either a server or mockAPI.
